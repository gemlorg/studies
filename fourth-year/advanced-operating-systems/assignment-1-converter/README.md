# Assignment 1: Binary file converter

A converter that rewrites AArch64 (ARM64) `ET_REL` relocatable object files into x86-64
`ET_REL` files — translating sections, the symbol table, relocations, and the machine code of
each function from the AArch64 instruction set to x86-64.

Original assignment statement:
<https://students.mimuw.edu.pl/ZSO/PUBLIC-SO/2024-2025/z1_elf/index-en.html>.

## Assignment

Input is one `ET_REL` / `EM_AARCH64` object file; output is one `ET_REL` / `EM_X86_64` object
file. The conversion must handle:

- **Sections** — `.note.gnu.property` and `*.eh_frame` sections are dropped (also from the
  section-name table); other sections carry over, with their function contents rewritten.
- **Symbols** (`SHT_SYMTAB`) — for defined `STT_FUNC`/`STT_OBJECT`/`STT_NOTYPE` symbols the value
  (and size for functions) is adjusted to the output layout; undefined symbols and
  `STT_SECTION`/`STT_FILE` are left unchanged.
- **Relocations** (`SHT_RELA`) — `R_AARCH64_CALL26`, `R_AARCH64_ADD_ABS_LO12_NC` and
  `R_AARCH64_ADR_PREL_PG_HI21` inside functions are converted per the instruction-conversion
  rules; `R_AARCH64_ABS64` outside functions becomes `R_X86_64_64`.
- **Functions** — each function is recognized by a fixed prologue/epilogue and its instructions
  are translated one by one, mapping the AArch64 register set onto x86-64 registers (with `r11`
  as the scratch register) and rewriting the prologue/epilogue so the frame and return value end
  up in the right place.

The program provides an executable `converter` with the interface:

```bash
./converter <input ET_REL file> <output ET_REL file>
```

## Solution overview

Written in C++ (C++23), using **Capstone** to disassemble AArch64 and **Keystone** to assemble
x86-64. Sources live in `arm_converter/`:

| File | Responsibility |
| --- | --- |
| `main.cpp` | Entry point: validate args, load the object, drop `.note.gnu.property`/`*.eh_frame`, run the converter, write the output. |
| `arm_converter.hpp` | Shared types: `section`, `string_table`, `relocation_table`, `program`, `converter`, and the register/condition maps. |
| `program.cpp` | ELF parsing and emission — reads the `Elf64` headers, sections, symbol and relocation tables, and writes the converted object back out. |
| `section.cpp` | Section, string-table and relocation-table helpers. |
| `converter.cpp` | The core: per-instruction AArch64 → x86-64 translation, register/condition mapping, prologue/epilogue rewriting, and relocation fix-ups. |
| `verify.cpp` | Argument/path validation. |

## Dependencies

`pkg-config`, `cmake`, `make`, `g++`, and the **Keystone** and **Capstone** engines. The
instructions below assume the QEMU lab image from the course.

## Building

```bash
./install_deps.sh   # builds/installs Keystone and Capstone
cmake .
make                # produces the ./converter executable
```

## Usage

```bash
./converter <input_aarch64_file.o> <output_x86_64_file.o>
```

## Tests

- `tests/` holds paired `*-aarch64.c` / `*-x64.c` cases (add, calls, conditional branches, loops,
  loads/stores, recursion, rodata, data relocations, …) plus `run.sh` and a `Makefile`.
- `example/` contains a minimal end-to-end example driven by its `Makefile`: it compiles an
  AArch64 object, runs `./converter` on it, links the result into an x86-64 `test` binary, and
  runs it. Build artifacts (the compiled `test` and `.o` files) are not checked in and are
  regenerated by `make`.
