# Literature for Deep Ritz Method and Finite Element Method

This directory collects references relevant to the thesis comparing the Deep Ritz Method with the classical Finite Element Method (FEM) for elliptic partial differential equations of the form $-\operatorname{div}(a(x) \nabla u(x)) + b(x) u(x) = f(x)$.

The file [`references.bib`](references.bib) provides BibTeX entries for citation in the thesis. Open-access PDFs for selected works are
stored in the [`pdfs`](pdfs) subdirectory for quick reference.

### Available PDFs

- Yulong Lu, Jianfeng Lu, and Min Wang, "A Priori Generalization Analysis of the Deep Ritz Method", 2021.
