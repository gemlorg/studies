## Introduction

Real matrices of size n\*m (n, m positive integers) can be represented in various ways. The most obvious is a two-dimensional array of type double. However, if we know more about the content of the matrix, we can choose other solutions, especially when we do not have enough memory to store every element of the matrix. For instance, we might not store those elements that appear most frequently. Typically, the most frequently repeated value is zero. Matrices where values different from this most frequent one rarely appear are called sparse matrices.

Sparse matrices can have very regular forms. Examples of such matrices are:

- **Zero Matrix**: Contains only zeros.
- **Constant Matrix**: Filled entirely with one value (e.g., the zero matrix is filled with zero).
- **Identity Matrix**: A square matrix with ones on the main diagonal (where the indices are equal) and zeros elsewhere.
- **Diagonal Matrix**: A square matrix with values only on the main diagonal (where the indices are equal).
- **Column Matrix**: All values in each row are the same, but rows may differ.
- **Row Matrix**: All values in each column are the same, but columns may differ.

There are also sparse matrices with irregular structures. These can be represented in various ways. A common method is an array of rows represented by lists – linked references to consecutive sparse (i.e., non-zero) values. Other possibilities include an array of column lists, a list of lists, or a dictionary. For irregular matrices, choose one of the implementations mentioned (excluding the dictionary) and include only that in the solution.

## Matrix Operations

Matrices can undergo various operations. The most basic is accessing a single element. Others include multiplication, addition, and subtraction with another matrix or a scalar (of type double). Additional operations involve calculating norms (e.g., maximum norm, Frobenius norm). Further operations include representing the matrix as a two-dimensional array of type double or as a string (toString). The matrix should also be able to provide its dimensions.
